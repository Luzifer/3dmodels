# Luzifer / 3dmodels

This repository contains various 3D models I built for personal use. The models are defined as JavaScript code using [JSCAD](https://openjscad.xyz/) and rendered to `*.stl` files.

GitHub can preview the generated STL files linked below. To modify a model, download its JSCAD source file and load it into the JSCAD web application, or render it locally using the JSCAD CLI:

```console
pnpm exec jscad model.jscad -o model.stl
```
